Kitchen Reusables

Reuse first. Waste less.

What's in the kitchens

Gateway's social kitchens run on a reuse-first system. Reusable dishware is the default for everyone.

  • Reusable plates, bowls, and cups
  • Reusable utensils
  • Dishwashing equipment
  • Cleaning and return stations

How it works

  1. Use. Choose reusable dishware for meals, snacks, and drinks.
  2. Sort. Scrape food scraps into the compost bin, or the Mill in the 1st floor social kitchen. Sort everything else properly.
  3. Clean. Load the dishwasher or leave dishware in the cleaning area.

Help keep it running

  • Skip single-use items whenever you can.
  • Keep shared dishware in the kitchen so it's there for the next person.
  • Leave the kitchen clean for shared use.
  • Items missing or supplies low? Let Sam Bunke know.

When reusables aren't an option

Only when reusables truly aren't feasible, use the next best option provided, such as approved compostables, and sort it properly after use.
